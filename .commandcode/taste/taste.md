# Taste

## Workflow

- Prefers TDD when implementing a change: write the failing test first, then implement until it passes. Confidence: 0.8

## Documentation

- Prefers feature/behavior documentation kept in a dedicated doc (e.g. `docs/userflows.md`) rather than expanded inline in the README; the README should stay high-level and link out instead of duplicating. Confidence: 0.6
